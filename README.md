# Hangman

A command-line Hangman game made with Python. The computer picks a random word, and you try to guess it one letter at a time before you run out of lives.

## How to play
1. The game chooses a random word and shows it as blanks (for example: _ _ _ _ _).
2. Type one letter at a time.
3. If the letter is in the word, it appears in the right places.
4. If not, you lose a life and the hangman drawing grows.
5. You win by guessing the whole word. You lose if you run out of lives.


## How to run
1. Install Python 3
2. Download or clone this repository
3. Run:
   python main.py

## Built with
- Python (`random` module)
